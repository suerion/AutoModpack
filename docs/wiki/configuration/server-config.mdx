# Server Configuration Reference
------------------------------------

The AutoModpack server configuration is stored in:

```text
~/.minecraft/automodpack/automodpack-server.json
```

AutoModpack generates this file automatically after the server starts for the first time.

Always modify the configuration generated by your installed version. Fields and defaults may change between AutoModpack releases.

------------------------------------
## Default Configuration
------------------------------------

```json
{
  "DO_NOT_CHANGE_IT": 2,
  "modpackName": "",
  "modpackHost": true,
  "generateModpackOnStart": true,
  "syncedFiles": [
    "!/kubejs/server_scripts/**",
    "/mods/*.jar",
    "/kubejs/**",
    "/emotes/*"
  ],
  "allowEditsInFiles": [
    "/config/**",
    "/options.txt"
  ],
  "forceCopyFilesToStandardLocation": [],
  "nonModpackFilesToDelete": {},
  "autoExcludeServerSideMods": true,
  "autoExcludeUnnecessaryFiles": true,
  "requireAutoModpackOnClient": true,
  "nagUnModdedClients": true,
  "nagMessage": "This server provides dedicated modpack through AutoModpack!",
  "nagClickableMessage": "Click here to get the AutoModpack!",
  "nagClickableLink": "https://modrinth.com/project/automodpack",
  "bindAddress": "",
  "bindPort": -1,
  "addressToSend": "",
  "portToSend": -1,
  "disableInternalTLS": false,
  "requireMagicPackets": false,
  "updateIpsOnEveryStart": false,
  "bandwidthLimit": 0,
  "validateSecrets": true,
  "secretLifetime": 336,
  "selfUpdater": false,
  "acceptedLoaders": [
    "fabric"
  ]
}
```

> **Important**
>
> Do not replace your generated configuration with this example. Use it as a reference and modify the file created by your installed AutoModpack version.

## Configuration Options
------------------------------------

| Setting | Default | Description |
| --- | --- | --- |
| `DO_NOT_CHANGE_IT` | `2` | Internal configuration version used for automatic migration. Do not modify manually. |
| `modpackName` | `""` | Display name of the modpack. |
| `modpackHost` | `true` | Enables AutoModpack's integrated modpack host. |
| `generateModpackOnStart` | `true` | Regenerates modpack information when the server starts. |
| `syncedFiles` | See default config | Included and excluded server files. Supports glob patterns. |
| `allowEditsInFiles` | `["/config/**", "/options.txt"]` | Synchronized files that players may modify locally. |
| `forceCopyFilesToStandardLocation` | `[]` | Files copied into standard Minecraft folders for compatibility. |
| `nonModpackFilesToDelete` | `{}` | Exact non-modpack files that may be removed from clients using hashes. |
| `autoExcludeServerSideMods` | `true` | Automatically excludes recognized server-only mods. |
| `autoExcludeUnnecessaryFiles` | `true` | Automatically excludes unnecessary, hidden, temporary, disabled, empty, or backup files. |
| `requireAutoModpackOnClient` | `true` | Requires players to have AutoModpack installed. |
| `nagUnModdedClients` | `true` | Shows an installation message when AutoModpack is not required. |
| `nagMessage` | Default message | Main message shown to players without AutoModpack. |
| `nagClickableMessage` | Default clickable message | Clickable part of the installation message. |
| `nagClickableLink` | Modrinth URL | Link opened by the clickable message. |
| `bindAddress` | `""` | Local address used by the AutoModpack listener. |
| `bindPort` | `-1` | Local port used by the AutoModpack listener. |
| `addressToSend` | `""` | Public hostname or IP address advertised to clients. |
| `portToSend` | `-1` | Public port advertised to clients. |
| `disableInternalTLS` | `false` | Disables internal TLS termination for advanced externally terminated setups. |
| `requireMagicPackets` | `false` | Requires the AutoModpack connection marker before accepting a modpack connection. |
| `updateIpsOnEveryStart` | `false` | Refreshes detected IP information whenever the server starts. |
| `bandwidthLimit` | `0` | Upload bandwidth limit in Mbps. `0` means unlimited. |
| `validateSecrets` | `true` | Requires temporary client secrets for hosted downloads. |
| `secretLifetime` | `336` | Secret lifetime in hours. `336` hours equals 14 days. |
| `selfUpdater` | `false` | Enables automatic updating of the AutoModpack server `.jar`. |
| `acceptedLoaders` | `["fabric"]` | Mod loaders accepted by the server. |

## Path Patterns
------------------------------------

The following settings support glob-style path patterns:

- `syncedFiles`
- `allowEditsInFiles`
- `forceCopyFilesToStandardLocation`

Use paths relative to the server root.

### Single-level wildcard

```text
*
```

Matches files inside one directory.

Example:

```text
/mods/*.jar
```

### Recursive wildcard

```text
**
```

Matches files recursively through subdirectories.

Example:

```text
/config/**
```

### Exclusion

```text
!
```

Excludes matching content.

Example:

```text
!/kubejs/server_scripts/**
```

------------------------------------
## Reloading the Configuration
------------------------------------

After editing the configuration, reload it using:

```text
/automodpack config reload
```

You can also restart the server.

If the file contains invalid JSON, AutoModpack may reject the changes or restore invalid values to defaults.
