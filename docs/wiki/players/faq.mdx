# Frequently Asked Questions
------------------------------------

Here you'll find answers to the most common questions about using AutoModpack as a player.

If you can't find the answer you're looking for, continue with the Troubleshooting section or ask in the AutoModpack Discord server.

------------------------------------
## Do I need to download the entire modpack manually?
------------------------------------

No.

Once AutoModpack is installed, it automatically downloads the required files when you join an AutoModpack server.

------------------------------------
## Do I need to install every mod manually?
------------------------------------

No.

Only AutoModpack needs to be installed manually.

Everything else is downloaded and managed automatically.

------------------------------------
## Where are my downloaded mods?
------------------------------------

Downloaded mods are stored inside AutoModpack's own modpack directory instead of your default Minecraft `mods` folder.

Learn more here:

[→ Where are the Downloaded Files](players/downloaded-files)

------------------------------------
## Can I use my own client-side mods?
------------------------------------

Yes.

As long as the mod only affects your own Minecraft client and does not require server support, you can continue using it.

Learn more here:

[→ Personal Client Mods](players/personal-client-mods)

------------------------------------
## Can I Use Different Client Mods on Different Servers?
------------------------------------

Yes.

AutoModpack keeps each server's modpack separate from your own client-side mods.

This allows you to use different modpacks on different servers without manually switching files.

Your own compatible client-side mods remain available across all servers unless they conflict with a server's modpack.

------------------------------------
## Why did AutoModpack remove one of my mods?
------------------------------------

If the server already provides the same mod, AutoModpack may remove the duplicate copy from your default `mods` folder to avoid version conflicts.

Learn more here:

[→ Where are the Downloaded Files](players/downloaded-files)

------------------------------------
## Do I need to download updates manually?
------------------------------------

No.

When the server owner updates the modpack, AutoModpack automatically downloads the required changes the next time you connect.

------------------------------------
## Can I Join Vanilla Servers?
------------------------------------

Yes.

AutoModpack only becomes active when joining an AutoModpack-enabled server.

You can continue using the same Minecraft installation to join vanilla servers or servers that do not use AutoModpack.

------------------------------------
## Can I Delete the Downloaded Modpack?
------------------------------------

Yes.

AutoModpack will simply download it again the next time you join the server.

Deleting the downloaded modpack can also be helpful when troubleshooting, as AutoModpack will download a fresh copy of all required files the next time you connect.

------------------------------------
## What Happens If I Delete the Entire AutoModpack Folder?
------------------------------------

Deleting the entire `~/automodpack/` folder completely resets AutoModpack.

This removes:

- All downloaded modpacks
- Downloaded configuration files
- Cached data
- Saved server certificate fingerprints
- Other AutoModpack data

The next time you join a server, AutoModpack behaves as if it is connecting for the first time.

Depending on the server configuration, you may need to verify the server again or re-enter the server's certificate fingerprint before the modpack can be downloaded.

If you only want to re-download a modpack, delete the downloaded modpack instead of the entire AutoModpack folder.

------------------------------------
## Does AutoModpack Work with Every Launcher and Mod Loader?
------------------------------------

AutoModpack does not require a specific launcher.

As long as your launcher supports Fabric, Forge, or NeoForge mods, AutoModpack can be installed like any other Minecraft mod.

Some launchers, mod loaders, or launcher-specific features may not be compatible with AutoModpack.

For the latest compatibility information, see:

[→ Compatibility](compatibility/)
