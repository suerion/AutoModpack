# Installing AutoModpack
------------------------------------

Before you can join an AutoModpack server, you need to install AutoModpack on your Minecraft client.

AutoModpack does not require a specific launcher. As long as your launcher supports Fabric, Forge, or NeoForge mods, AutoModpack can be installed like any other Minecraft mod.

------------------------------------
## Requirements
------------------------------------

Before installing AutoModpack, make sure you have:

- Minecraft installed
- The correct Minecraft version
- The correct mod loader (Fabric, Forge, or NeoForge)

If you are unsure which versions to use, ask the server owner or modpack author.

------------------------------------
## Download AutoModpack
------------------------------------

Download the AutoModpack version that matches your Minecraft version and mod loader.

You can download AutoModpack from:

- Modrinth
- CurseForge
- GitHub Releases

Always download AutoModpack from an official source.

------------------------------------
## Install AutoModpack
------------------------------------

Place the downloaded AutoModpack `.jar` file into your Minecraft instance's `mods` folder.

Example:

```text
.minecraft/
└── mods/
    └── automodpack.jar
```

That's all you need to join an AutoModpack server.

When you connect for the first time, AutoModpack automatically downloads and manages the server's modpack.

------------------------------------
## Verify the Installation
------------------------------------

Start Minecraft using the correct Minecraft version and mod loader.

If AutoModpack appears in the installed mods list, the installation was successful.

------------------------------------
## Common Installation Problems
------------------------------------

If AutoModpack does not appear in Minecraft, check the following:

- The correct Minecraft version is installed.
- The correct mod loader is being used.
- The AutoModpack `.jar` file is inside the correct `mods` folder.
- The file is not still inside a ZIP archive.
- You started the correct Minecraft instance.
