# Personal Client Mods
------------------------------------

One of the biggest advantages of AutoModpack is that you can continue using your own client-side mods alongside the server's modpack.

These mods only affect your own Minecraft client and do not need to be installed on the server.

> **Tip**
>
> AutoModpack keeps the server's modpack separate from your own client-side mods, allowing you to personalize your Minecraft experience without modifying the server's modpack.

------------------------------------
## What are Client-Side Mods?
------------------------------------

Client-side mods only affect your own Minecraft client.

They do not change the server, do not require installation on the server, and do not affect other players.

These mods typically improve or customize your own gameplay experience.

Examples include:

- Visual improvements
- Custom HUDs and overlays
- User interface enhancements
- Replay tools
- Accessibility features
- Client-only quality-of-life improvements

------------------------------------
## Which Mods Can I Use?
------------------------------------

In general, you can use any mod that only affects your own Minecraft client and does not require support from the server.

Common examples include:

- Shader support
- Custom HUDs
- Replay tools
- Inventory improvements
- Accessibility features
- Client-side visual enhancements

If you are unsure whether a mod is client-side, check the mod's documentation or ask the server owner, modpack author, or mod developer.

------------------------------------
## What Happens If the Server Already Includes the Same Mod?
------------------------------------

If the server already provides the same mod, AutoModpack may automatically remove the duplicate copy from your default Minecraft `mods` folder.

This prevents the same mod from being loaded twice and avoids version conflicts.

Learn more here:

[→ Where are the Downloaded Files](players/downloaded-files)

------------------------------------
## Mods That May Not Work
------------------------------------

Installing a mod only on your client does not automatically make it a client-side mod.

Some mods still require support from the server or a matching version on both the client and the server.

If such a mod is installed only on your client, you may experience:

- Connection failures
- Missing features
- Unexpected behavior
- Game crashes

If you are unsure, check the mod's documentation or ask the mod developer before installing it.

------------------------------------
## Best Practices
------------------------------------

For the best experience:

- Only install mods that are designed to work on the client.
- Avoid replacing mods already provided by the server.
- Test new client-side mods one at a time.
- Keep your personal mods separate from the server's modpack.
